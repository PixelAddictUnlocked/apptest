Admin Guide

How to use the Armour Care admin panel

Dashboard

The Dashboard is your overview of the current month's wellbeing data.

Summary Cards

Shows total registered users, submissions received this month, completion rate percentage, and the overall average wellbeing score.

Team Breakdown

Displays a table of all teams showing the number of members, submissions, completion rate, and average score per team. Helps identify which teams need attention.

Team Radar Charts

Visual radar charts for each team showing scores across Burnout, Mental Health, Sleep, and Lifestyle categories. Charts have colored borders indicating status (green for good, yellow for fair, red for needs attention). Click any chart to jump directly to that team's submissions.

Month Selector

Use the dropdown in the top-right to view data from previous months. The dashboard auto-refreshes every 30 seconds.

Users

Manage all registered users in the system.

User List

View all registered users with their Armour Number, team assignment, nickname, and registration date. A green bell icon indicates users who have subscribed to push notifications. Use the search bar to filter by Armour Number or nickname.

Edit Nickname

Click the Edit button next to a user to update their display nickname. This helps identify users more easily.

Delete User

Removes a user from the system entirely. This action cannot be undone. Their past submissions will remain in the data.

Team Filtering

Sub-admins can only see users belonging to the teams they have been assigned. The master admin can see all users.

Submissions

Review individual wellbeing survey submissions.

Submission List

Shows all users who have submitted their survey for the current month, grouped by team. Each row displays the user's overall wellbeing score with color coding (green for good, yellow for fair, red for needs attention). Click View to see a detailed breakdown.

Jump to Team

Use the "Jump to team" dropdown to quickly navigate to a specific team's submissions.

Wellbeing Report

Each submission shows a radar chart and score breakdown by category (e.g. Physical, Emotional, Social). Scores are displayed as percentages where 100% is the best outcome.

Reset Submission

If a user needs to re-submit their survey, click Reset to remove their submission for the selected month. They will then be able to complete it again.

Month Selector

Use the dropdown to view submissions from previous months.

Question Builder

Requires Permission

Create and manage the wellbeing survey questions.

Categories

Questions are organised into categories (e.g. Physical Health, Emotional Wellbeing). Each category groups related questions together and contributes to a section score on the radar chart.

Adding Questions

Click Add Question within a category to create a new question. Questions can be scored normally or reverse-scored (where a lower answer indicates a better outcome).

Reordering

Use the up/down arrows to reorder questions within a category, or reorder the categories themselves.

Backup & Restore

Use the Export button to download a backup of your questions as a JSON file. Use Import to restore from a backup.

Notifications

Requires Permission

Send push notifications to users and manage automated reminders.

Send Notification

Compose a title and message, then choose to send to all users or select specific recipients. Notifications are delivered via browser push notifications on their devices.

Auto Survey Reminder

When enabled, the system automatically sends a reminder on a specific date and time you choose. Use the date and time picker to schedule when the notification should be sent.

Notification History

View a log of all previously sent notifications, including the type, recipient count, and delivery stats.

Security

Requires Permission

Monitor all security-related activity across the platform.

Event Log

A chronological record of every security event: user registrations, login attempts (successful and failed), password changes, admin management actions, user deletions, and submission resets.

Summary Cards

Six at-a-glance metrics: total events, failed logins, registrations, user logins, admin actions, and unique IP addresses. Failed logins are highlighted in red when above zero.

Time Period Filter

Use the "Stats for" dropdown to filter the summary cards and event log by time period: Last Hour, Last 24 Hours, Last 7 Days, Last 30 Days, or All Time.

Filtering

Use the event type dropdown or the user search box to narrow down the log. Click Refresh to fetch the latest events on demand.

Notification Badge

When you log in, a red badge appears on the Security tab if there are recent events. The badge is dismissed once you visit the Security tab.

Delete Events

Individual events can be removed using the Delete button on each row. A confirmation prompt will appear before deletion.

Admins

Master Only

Manage administrator accounts. Only the master admin can access this section.

Add Admin

Create a new admin account with an Armour Number, password, nickname, team assignments, and permissions. Select All Teams to give access to every team.

Edit Admin

Update an admin's teams, nickname, password, and permissions. You can grant or revoke access to Question Builder, Notifications, and Security.

Permissions

Sub-admins only see the tabs they have permission for. Available permissions:

  • Question Builder — Create and edit survey questions
  • Notifications — Send push notifications and manage auto-reminders
  • Security — View the security audit log
Change Password

Click Password next to any admin to change their password. Admins can also change their own password. The master admin can change any admin's password.

Delete Admin

Remove an admin account. The master admin account cannot be deleted.

Good to Know

Team Access

Sub-admins only see data for the teams they are assigned to. The master admin sees everything. When creating a new admin, assigning All Teams gives full team visibility without master privileges.

Monthly Surveys

Each user can submit one wellbeing survey per month. Surveys reset automatically at the start of each calendar month. Users are shown their previous scores when they return.

Session & Security

Admin sessions last 7 days before requiring re-login. All passwords are securely hashed. Login attempts are rate-limited to prevent brute-force attacks. The platform enforces HTTPS and includes security headers on all responses.

Push Notifications

Users must grant notification permission in their browser for push notifications to work. Notifications are delivered via web push and will appear even when the app is not open.
